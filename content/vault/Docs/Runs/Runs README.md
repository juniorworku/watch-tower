# Runs

One write-up per bot run. Every time a bot does a full run (a [[Morning Brief]] edition, a pass through the [[Micro-MVP Workshop]] pipeline, etc.), it adds a note here.

- **File name:** `YYYY-MM-DD <Bot> run.md` (add a short suffix if a bot runs more than once a day).
- **Template:** `Templates/Run Write-up.md`.
- **Link it** from that day's daily log under the bot's heading, per [[Logging Protocol]].
