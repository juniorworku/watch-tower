# Micro-MVP Workshop

A general pipeline for turning a real pain point into a small shipped product and a write-up. Run by [[Micro-MVP Workshop Bot]]. (Corrected on 2026-10-17: this is a general pipeline, not a quiz app.)

## Pipeline
1. **Pain point**: Junior brings an idea / problem.
2. **Validate with real evidence**.
3. **One-page spec**.
4. **Static MVP**.
5. **Junior reviews**.
6. **Deploy to Vercel** (only after Junior's review).
7. **Write-up for Substack**.
